# Netflix TOP10 Analysis

넷플릭스 TOP10 데이터를 활용해
장기 흥행 콘텐츠의 특징을 분석하는 프로젝트입니다.

## 프로젝트 주제

넷플릭스 TOP10 데이터를 활용한 장기 흥행 콘텐츠 특징 분석

## 분석 목표

- 영화와 TV 콘텐츠의 TOP10 유지 기간 비교
- 첫 진입 순위와 흥행 지속 기간의 관계 확인
- 첫 주 시청시간과 장기 흥행의 관계 확인
- 국가별 확산 정도와 장기 흥행의 관계 확인

## 사용 예정 데이터

- Netflix TOP10 Global Weekly Data
- Netflix TOP10 Countries Weekly Data

## 사용 환경

- Python
- Google Colab
- pandas
- matplotlib
- seaborn
- scikit-learn

## 진행 상태

현재 데이터 확인 및 분석 환경 설정을 진행하고 있습니다.

추후 EDA와 모델링 결과를 순차적으로 업데이트할 예정입니다.
