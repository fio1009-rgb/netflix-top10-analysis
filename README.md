# 1차 프로젝트 데이터

이 폴더에는 4개 산업의 데이터가 들어 있습니다. **이 중 하나를 골라서** EDA와 기초 모델링, 인사이트 리포트를 진행합니다.

먼저 아래 "데이터 고르기"를 읽고 하나를 정하세요. 그다음부터는 고른 산업의 섹션 하나만 보면 됩니다. 나머지는 읽지 않아도 돼요.

파일을 직접 고치거나 지워도 괜찮습니다. 원본은 따로 보관되어 있어서 언제든 다시 받을 수 있습니다.

## 데이터 고르기

| 산업 | 데이터 | 규모 | 파일 | 난이도 | 이런 분석에 어울려요 |
|---|---|---|---|---|---|
| 바이오 | 당뇨 건강지표 | 25만 명 × 22개 항목 | 3개 중 1개 사용 | 쉬움 | 분류 예측, 변수 중요도 분석 |
| 엔터 | 넷플릭스 주간 Top 10 | 29주, 94개국 | 2개 | 보통 | 순위 변화 분석, 잔류 예측 |
| 금융 | 금융상품과 소비자 특성 | 거래 38만 건, 상품 1만 개 | 압축 40개 | 어려움 | 고객 세분화, 상품 추천 |
| 유통 | 서울시 상권분석 | 2021년 1분기부터 2026년 1분기까지 | 72개 | 어려움 | 매출 예측, 상권 유형 분석, 지도 시각화 |

고를 때 이렇게 생각해 보세요.

- **분석 자체에 집중하고 싶다면 바이오**를 고르세요. 파일 하나를 그대로 읽으면 바로 시작할 수 있고, 모든 값이 숫자라 전처리에 시간을 쓰지 않아도 됩니다.
- **시간 흐름을 다뤄 보고 싶다면 엔터**가 좋아요. 데이터가 작아서 가볍지만, 예측 문제를 직접 정의해야 해서 생각할 거리가 많습니다.
- **텍스트나 추천을 다뤄 보고 싶다면 금융**을 고르세요. 표와 문서가 섞여 있어서 데이터를 모으는 과정부터 직접 설계해야 해요.
- **가장 넓게 파고 싶다면 유통**입니다. 표가 많아 손은 가지만, 매출과 인구와 점포를 엮어서 다른 데이터로는 못 하는 분석을 할 수 있어요.

난이도는 분석의 어려움이 아니라 **데이터를 다루기 시작할 때까지 드는 품**을 뜻합니다. 어려움으로 표시된 데이터도 아래 안내를 따라가면 첫 표는 만들 수 있어요.

## 바이오를 골랐다면

미국 CDC가 2015년에 진행한 건강 설문입니다. 혈압, 콜레스테롤, BMI, 흡연 여부 같은 21개 지표로 당뇨 여부를 예측합니다.

폴더에 파일이 세 개 있는데, **하나만 골라서 씁니다.** 같은 사람의 응답이 세 파일에 나눠 들어 있어서, 섞으면 결과를 믿을 수 없게 돼요.

| 파일 | 행 | 타깃 | 어떤 경우에 고르나요 |
|---|---|---|---|
| `diabetes_binary_health_indicators_BRFSS2015.csv` | 253,680 | 당뇨 여부 | 기본으로 추천해요. 양성 비율 13.9%로 실제와 가깝습니다 |
| `diabetes_binary_5050split_health_indicators_BRFSS2015.csv` | 70,692 | 당뇨 여부 | 양성과 음성이 반반이라 다루기 쉽지만, 실제 비율이 사라집니다 |
| `diabetes_012_health_indicators_BRFSS2015.csv` | 253,680 | 3단계 | 당뇨 전 단계까지 나누고 싶을 때 씁니다. 전 단계가 4,631건뿐이라 어려워요 |

```python
import pandas as pd

df = pd.read_csv("diabetes_binary_health_indicators_BRFSS2015.csv")
df["Diabetes_binary"].value_counts()
```

시작하기 전에 두 가지만 기억하세요. 값이 전부 숫자로 저장되어 있지만 `Age`, `GenHlth`, `Education`, `Income`은 실제 나이나 금액이 아니라 **구간 번호**예요. 진짜 연속형 값은 `BMI`, `MentHlth`, `PhysHlth` 세 개뿐입니다. 그리고 양성이 13.9%인 불균형 데이터라, 정확도만 보면 전부 음성으로 찍어도 86%가 나와요. 정밀도와 리콜을 함께 봐야 합니다.

## 엔터를 골랐다면

넷플릭스가 공개한 주간 Top 10 순위입니다. 2021년 7월 4일부터 2022년 1월 16일까지 29주 분량입니다.

| 파일 | 행 | 특징 |
|---|---|---|
| `all-weeks-global.csv` | 1,160 | 전 세계 순위. 시청 시간(`weekly_hours_viewed`)이 있습니다 |
| `all-weeks-countries.csv` | 54,520 | 94개국 순위. 시청 시간 없이 순위만 있어요 |

국가별 파일은 글자를 저장한 방식이 달라서 그냥 읽으면 오류가 납니다. `encoding`을 꼭 지정하세요.

```python
import pandas as pd

world = pd.read_csv("all-weeks-global.csv", parse_dates=["week"])
country = pd.read_csv("all-weeks-countries.csv", encoding="cp1252", parse_dates=["week"])
```

전 세계 파일부터 보고 국가별로 넓히는 순서를 권해요. 시청 시간이 전 세계 파일에만 있어서, 국가별 시청량을 예측하는 문제는 만들 수 없습니다. 국가 데이터는 순위 중심으로 설계하세요.

그리고 순위표는 10위에서 잘려 있어요. 다음 주에 사라진 작품이 곧 이탈이라는 뜻이라, **잔류와 이탈 라벨은 두 주를 비교해서 직접 만들어야 합니다.** 기간이 29주로 짧아서 학습에 쓸 구간이 20주 남짓이라는 점도 미리 감안해 주세요.

## 금융을 골랐다면

고객의 거래 내역과 금융상품 정보, 상담 시나리오가 함께 들어 있습니다. 표와 문서가 섞여 있어서, 무엇을 쓸지 먼저 정하고 시작하는 편이 좋아요.

```
Training/01.원천데이터/     금융상품 1만 개, 상품마다 JSON 파일 하나
Training/02.라벨링데이터/   소비자.csv와 상담 시나리오
Validation/                 위와 같은 구성
```

가장 쉬운 출발점은 `소비자.csv` 하나입니다. 압축을 풀고 바로 읽을 수 있습니다. 거래 385,019건에 나이, 성별, 지역, 투자성향, 신용등급, 거래금액 등 22개 항목이 담겨 있습니다.

```python
import pandas as pd

df = pd.read_csv("Training/02.라벨링데이터/TL_2.소비자.zip", encoding="utf-8-sig")
df.head()
```

여기서 고객 세분화까지 해 본 다음, 상품 정보를 붙이고 싶으면 원천데이터의 JSON을 `product_name` 기준으로 이어 붙이세요.

주의할 점이 두 가지 있어요. `Training`과 `Validation` 폴더의 상품 정보와 `소비자.csv`는 **내용이 완전히 같은 파일입니다.** 두 폴더를 합쳐서 학습하면 정답을 미리 보고 푸는 셈이 되니, 학습과 검증을 나누는 기준은 직접 정해야 해요. 또 `700점대`나 `3000만원미만`처럼 숫자처럼 보이는 값이 사실은 글자입니다. 계산에 쓰려면 숫자로 바꾸는 작업이 먼저 필요해요.

## 유통을 골랐다면

서울시가 분기마다 공개하는 상권 데이터입니다. 매출, 점포 수, 인구, 소비, 집객시설 등 10개 주제를 상권, 상권배후지, 행정동, 자치구, 서울시 다섯 단위로 제공합니다.

파일 이름이 `주제-공간단위` 형태입니다. `서울시 상권분석서비스(추정매출-행정동)_2024년.zip`은 행정동별 추정매출이에요. 파일이 72개나 되지만 전부 쓸 필요는 없습니다. **공간 단위 하나를 정하고, 필요한 주제만 골라 합치세요.**

한글이 윈도우 방식으로 저장되어 있어서 `encoding="cp949"`를 반드시 넣어야 합니다. 압축 파일은 풀지 않고 그대로 읽을 수 있어요.

```python
import pandas as pd, glob

# 상권 단위로 매출과 인구를 합치는 예시
sales = pd.concat(
    [pd.read_csv(f, encoding="cp949")
     for f in sorted(glob.glob("*상권분석서비스(추정매출-상권)_*.zip"))],
    ignore_index=True,
)
pop = pd.read_csv("서울시 상권분석서비스(상주인구-상권).csv", encoding="cp949")

df = sales.merge(pop, on=["기준_년분기_코드", "상권_코드"])
```

추정매출과 점포는 연도별로 나뉘어 있어서 위처럼 이어 붙여야 전체 기간이 됩니다. 나머지 주제는 파일 하나에 전 기간이 들어 있어요.

기억해 둘 점이 세 가지 있습니다. `기준_년분기_코드`는 20244처럼 연도 네 자리와 분기 한 자리가 붙은 값인데, **20214 다음이 20221이라 그냥 정렬하면 순서가 어긋나요.** 연도와 분기로 나눠서 쓰는 편이 안전합니다. 그리고 상권과 상권배후지는 서로 다른 영역이라 두 값을 더하면 같은 매출을 두 번 세게 돼요. 마지막으로 `영역` 파일 네 개는 표가 아니라 지도 파일입니다. 지도에 그릴 때만 쓰고, `geopandas`가 필요해요.
